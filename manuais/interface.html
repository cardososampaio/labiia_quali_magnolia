Conhecendo a tela

Esta página percorre a janela do labiia_quali de cima para baixo: a barra de título, a faixa de opções com todas as abas, os painéis, a barra de status e as Preferências. No fim há a lista de atalhos de teclado.

Tela de boas-vindas

Quando nenhum projeto está aberto, o programa mostra a tela inicial. Ela tem três partes úteis:

  • Projetos recentes, na parte de cima à esquerda. Clique em um nome para abrir o projeto. Se a lista estiver vazia, aparece a mensagem Ainda não há projetos recentes. O botão Limpar esvazia a lista (não apaga nenhum arquivo).
  • Botões de ação, embaixo à esquerda: Novo cria um projeto novo; Abrir… escolhe um arquivo .qdpx; Sair fecha o programa, depois de pedir confirmação.
  • Créditos, também embaixo à esquerda, com o nome da versão. O lado direito da tela é só decoração.

A janela principal

Com um projeto aberto, a janela tem quatro partes, de cima para baixo:

  1. Barra de título

    Botão Iniciar, botões rápidos, nome do projeto e controles da janela.

  2. Faixa de opções

    Abas com botões grandes, como no Office. Cada aba reúne botões por assunto.

  3. Área principal

    Painéis com as listas (documentos, códigos e outros) e, no centro, a área onde o documento aparece.

  4. Barra de status

    Rodapé com o estado do projeto e as contagens.

Barra de título

A barra de título fica no alto da janela. Da esquerda para a direita:

Elementos da barra de título
Elemento O que faz
Iniciar (ícone do programa) Abre o menu Iniciar, descrito logo abaixo.
Salvar (disquete) Grava o projeto. Atalho: Ctrl + S.
Desfazer (seta curva) Desfaz a última alteração. Fica apagado quando não há o que desfazer. Atalho: Ctrl + Z.
Refazer Refaz o que foi desfeito. Atalho: Ctrl + Shift + Z.
Nome do projeto, com o estado embaixo Mostra o nome e o estado: Ainda não salvo, Editado (há alterações não gravadas) ou Salvo. Clicar nele abre as informações do projeto.
Bloqueado (botão vermelho) Aparece só quando outra pessoa está com o projeto. Clicar nele abre o aviso de conflito (veja a página Projetos).
Minimizar, Maximizar / Restaurar, Fechar Controles comuns da janela. Fechar o programa pede confirmação.

Botão Iniciar

Clique no ícone do programa, no canto esquerdo, ou pressione Alt + Home. Para fechar o menu sem escolher nada, use Esc ou clique fora dele.

Itens do menu Iniciar
Item O que faz
Novo projeto Cria um projeto vazio, com um arquivo novo.
Abrir projeto… Abre um arquivo .qdpx pela janela de arquivos do Windows.
Salvar como… Grava uma cópia do projeto com outro nome. Daí em diante, você trabalha na cópia.
Importar fontes… Abre a escolha de arquivos para importar documentos. Fica desabilitado quando outra pessoa está com o projeto.
Mesclar projetos… Traz para o seu projeto o trabalho de outra cópia do mesmo projeto. Esta é a única entrada para mesclar; veja Projetos.
Projetos recentes (lista) Até 8 projetos abertos por último. Clique para abrir. Se a lista estiver vazia: Os projetos que você abrir aparecem aqui.

Informações do projeto

Clique no nome do projeto, na barra de título, para abrir a janela Detalhes do projeto:

  • Nome do projeto e Descrição: campos que você pode editar.
  • Arquivo (caminho do arquivo, ou Não salvo) e Tamanho do arquivo: só leitura.
  • Documentos e Códigos: contagens do projeto, só leitura.

O botão Concluído fecha a janela.

Faixa de opções

A faixa de opções é a fileira de abas logo abaixo da barra de título. Cada aba mostra grupos de botões com um nome em cima. Ao clicar num botão, a ação começa na hora. Alguns botões abrem uma janela para você escolher algo antes.

As cores dos botões seguem a família da ação, como explicado em Como ler este manual. Um botão esmaecido, com o motivo na dica (o aviso que aparece ao passar o mouse), está indisponível no momento. Ao clicar nele, o programa explica o motivo.

Recolher a faixa

Para ganhar espaço na tela, você pode recolher a faixa. Para isso, use qualquer um destes caminhos:

  • dê duplo clique em uma das abas;
  • pressione Ctrl + F1;
  • clique na seta no fim da linha de abas.

Com a faixa recolhida, clicar numa aba mostra o conteúdo dela. Ele some quando você clica em outro lugar. Use as setas ← e → para trocar de aba com o teclado. A escolha (recolhida ou não) e a última aba aberta ficam salvas neste computador.

Aba Exibir

Esta aba controla o que aparece na tela. Os botões de Painéis ligam e desligam cada painel: o botão fica marcado enquanto o painel está visível.

  • Modo escuro / Modo claro: troca entre o tema claro e o escuro da família atual. Cada tema tem uma versão clara e uma escura, por exemplo Windows e Windows escuro.
  • Aumentar / Diminuir: aumenta ou diminui o tamanho da interface, em passos de 100%, 125%, 150% e 200%.

Painéis principais

Os painéis são as listas e as áreas que aparecem ao redor do documento. Você pode ligar e desligar cada um pela aba Exibir, no grupo Painéis, ou fechá-lo pelo próprio botão de fechar no painel.

Características Dentro do painel Documentos Oculto As características dos documentos (por exemplo, dados de cada participante) e os atributos que as agrupam.

No centro da tela fica a área de visualização. É nela que o documento aberto aparece, e onde as análises e outras telas também abrem, em abas. Para procurar uma palavra no documento aberto, pressione Ctrl + F.

Preferências

Abra as Preferências pelo botão Preferências, na aba Ajuda. Elas abrem numa aba do programa, com as categorias à esquerda e as opções à direita. Cada opção é gravada assim que você muda. O botão Fechar, no alto, fecha a aba.

Geral

  • Idioma: Português (Brasil) ou English. A troca vale só na próxima vez que o programa abrir.
  • Seu nome: o nome usado para mostrar quem alterou o projeto, no bloqueio e na mesclagem.

Reprodução de mídia

Usada para áudio e vídeo importados. Para cada ação, clique no campo e pressione a tecla que quer usar:

  • Reproduzir / Pausar: padrão F5.
  • Voltar: padrão F6.
  • Avançar: padrão F7.
  • Segundos ao voltar e Segundos ao avançar: de 1 a 60 segundos (padrão 5).
  • Velocidade padrão de reprodução: 0.5x, 0.75x, 1x, 1.25x, 1.5x ou 2x (padrão 1x).

Tamanho do papel

Define o papel dos PDFs exportados: documentos codificados, resultados de consultas, livros de códigos, diário de bordo e resumos de questionários. As opções são A4 (padrão), A3, A5, Letter, Legal e Tabloid.

R

Mostra o R em uso, a pasta dos pacotes e os pacotes instalados, além dos botões para encontrar, indicar ou instalar o R. Todo o passo a passo está em Instalação e R.
