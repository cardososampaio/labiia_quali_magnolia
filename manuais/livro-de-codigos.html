Livro de códigos

O livro de códigos é a lista completa dos códigos do projeto, com nome, cor, descrição e atalho. Esta página mostra como consultá-lo, como trocar códigos com outros programas e como montar o livro a partir de um documento de texto que você já tenha escrito.

O que é o livro de códigos

Em uma pesquisa qualitativa, o livro de códigos é o dicionário da análise: ele diz o que cada código significa e onde ele se encaixa na hierarquia. Ele pode servir a três finalidades:

  • Consultar e revisar as definições dos códigos, na janela Livro de códigos.
  • Levar a outro projeto ou programa, por meio de um arquivo .qdc, que segue o padrão REFI-QDA.
  • Começar de um roteiro pronto, importando um livro de códigos que você escreveu antes num documento Word, OpenDocument, RTF ou Markdown.

A janela Livro de códigos

Para abrir, use o botão Livro de códigos no grupo Codificação da barra, ou o menu Códigos > Livro de códigos. A janela abre separada da janela principal.

Ela tem duas partes. À esquerda, a lista de todos os códigos, com a hierarquia. À direita, os detalhes do código selecionado. No topo, aparecem o título, a quantidade de códigos e os botões de importar e exportar.

Editar um código

  1. Selecione o código

    Um clique mostra os detalhes à direita.

  2. Dê duplo clique para editar

    Abre a janela Editar código.

  3. Altere os campos e clique em Salvar

    As mudanças vão para o projeto principal.

Campos de um código
Campo O que é
Nome O nome do código, como aparece no painel Códigos e nas consultas.
Cor A cor do código nas margens do texto. Escolha uma cor da paleta ou use Personalizada.
Descrição Um texto com formatação que explica o critério de uso do código. Quem tem descrição mostra um ícone de memo na lista.
Atalho Um número de 0 a 9 para aplicar o código com Ctrl + número, como explicado na página Codificação.
A janela só edita

Pela janela Livro de códigos você altera nome, cor, descrição e atalho. Para criar, excluir, mover ou mesclar códigos, use o painel Códigos. Se você fez mudanças no painel enquanto a janela estava aberta, feche e abra a janela de novo para vê-las.

Exportar o livro de códigos

O livro pode sair do projeto de três formas:

Formas de exportar
Botão Onde está O que gera
Exportar QDC Janela Livro de códigos, ou menu Códigos > Exportar livro de códigos (.qdc)… Um arquivo .qdc (REFI-QDA), com a hierarquia, os nomes, as cores e as descrições.
Exportar PDF Janela Livro de códigos Um relatório em PDF da árvore de códigos, com a descrição de cada um.
Os atalhos não vão para o arquivo .qdc

O atalho de teclado (0 a 9) de cada código não é gravado no arquivo .qdc. Se você importar o arquivo em outro lugar, precisará definir os atalhos de novo.

Importar um arquivo .qdc

Um arquivo .qdc pode ter sido exportado deste programa ou de outro que siga o padrão REFI-QDA.

  1. Clique em Importar livro de códigos

    Está na janela Livro de códigos, ou em Códigos > Importar livro de códigos (.qdc)… no menu.

  2. Escolha o arquivo .qdc

    Os códigos entram direto. Não há prévia para arquivos .qdc.

Três regras ajudam a entender o resultado:

  • Códigos que já existem no projeto, reconhecidos pelo identificador interno, não entram de novo. Assim, reimportar o mesmo arquivo não duplica tudo.
  • Os códigos novos entram no fim da lista principal, no nível de cima. Eles não são colocados dentro de códigos que já existem.
  • O programa não compara nomes. Um código com nome igual a outro existente, mas de origem diferente, entra como um código separado. Veja a seção Nomes repetidos abaixo.

Importar de um documento de texto

Se você já escreveu o seu livro de códigos num arquivo de texto, pode importá-lo sem recriar nada. São aceitos estes formatos:

  • Word: .docx e .doc (formato antigo)
  • OpenDocument: .odt (LibreOffice e outros)
  • Rich Text: .rtf
  • Markdown: .md
Sobre o formato .doc

O formato antigo do Word é convertido antes da leitura, usando o próprio Word ou o LibreOffice, se algum deles estiver instalado. Se nenhum estiver, abra o arquivo no Word ou no LibreOffice, salve como .docx e importe esse arquivo.

Passo a passo

  1. Escolha o arquivo

    Clique em Importar livro de códigos e selecione o documento.

  2. Confira a prévia

    Abre uma janela com as categorias e os códigos encontrados. Nada entra no projeto antes de você clicar em Importar.

  3. Escolha a leitura certa

    O programa já escolhe uma leitura. Se não for a que você quer, clique em outra das três (veja abaixo).

  4. Ajuste as linhas

    Desmarque o que não deve entrar, mude níveis com as setas e decida se os números ficam nos nomes.

  5. Clique em Importar

    Os códigos entram no projeto, cada categoria com uma cor, e os códigos dela com a mesma cor.

Como o programa reconhece a estrutura

O programa lê o documento de um de três jeitos. Cada jeito é uma regra de leitura, e você vê as três nos botões no topo da prévia. Um documento é lido por uma regra só: não misture formas diferentes no mesmo arquivo.

Jeito 1: Títulos do Word

É o mais seguro. Você marca cada linha com um estilo de título: Título 1 para categoria, Título 2 para código e Título 3 para subcódigo. O programa reconhece o estilo, não o tamanho da letra, então use sempre a lista de estilos do Word.

Em Markdown, a mesma estrutura usa # para categoria, ## para código e ### para subcódigo.

Jeito 2: Negrito e número

Aqui a estrutura vem do número e do negrito. Uma linha inteira em negrito que começa com número é categoria, por exemplo 1. Nível de reflexão. As linhas numeradas que não estão em negrito são os códigos dessa categoria, por exemplo 0. nenhuma e 1. opinião.

Esta regra só funciona se houver pelo menos uma categoria em negrito com número. Sem ela, o documento é lido pela regra de numeração.

Jeito 3: Numeração

A própria numeração mostra o nível. 1. é categoria, 1.1 é código e 1.1.1 é subcódigo. Se o seu documento usar uma lista numerada do Word com vários níveis, o nível da lista também serve.

Qual leitura o programa escolhe

Ao abrir a prévia, o programa testa as três regras e escolhe a que melhor explica o documento: aquela que monta categorias e códigos e encontra mais itens. Em caso de empate, vale a ordem Títulos do Word, Negrito e número, Numeração. A leitura escolhida aparece marcada com a palavra detectado, e o botão mostra quantos itens ela encontrou.

Você pode trocar a regra clicando em outro botão. A lista muda na hora, e nada é importado até você confirmar.

Texto abaixo de um item vira descrição

Parágrafos comuns logo abaixo de uma categoria ou de um código viram a descrição dele. Se houver mais de um parágrafo, todos entram juntos, separados por quebra de linha. A descrição é exibida na prévia e fica no código depois da importação.

A prévia, parte por parte

O que cada parte da prévia faz
Parte Para que serve
Botões de regra (Títulos do Word, Negrito e número, Numeração) Trocam a leitura do documento. Mostram quantos itens cada uma encontrou.
Aviso de nome e introdução Um título único no topo é tratado como nome do livro e não é importado. Parágrafos antes da primeira categoria também ficam de fora, e a prévia avisa quantos são.
Caixa de cada linha Desmarque para deixar o item de fora. Os itens seguintes se ligam ao item de nível acima que ficou.
Tipo de cada linha (Categoria, Código, Subcódigo) Mostra o nível que o programa atribuiu. Muda quando você move a linha com as setas.
Setas ← e → ← sobe a linha um nível. → desce um nível. Uma linha não pode ficar mais de um nível abaixo da linha de cima.
Manter os números nos nomes Quando marcado, o nome conserva o número, como “1. opinião”. Quando desmarcado, o nome fica só com o texto.
Rodapé (contagem, Cancelar, Importar) Mostra quantas categorias e códigos serão criados. Importar fica desligado se nenhuma linha estiver marcada.

Dicas para preparar o documento

  • Use estilos de título do Word. É a forma mais segura. Evite só deixar a letra maior ou em negrito.
  • Escolha uma forma e mantenha. Não misture títulos, negrito e números no mesmo documento.
  • Não pule níveis. Um código deve vir logo depois de uma categoria, e um subcódigo logo depois de um código.
  • Cuidado com o título geral. Se a primeira linha for um título e as demais forem títulos menores, ela vira o nome do livro e não é importada. Se a primeira categoria precisa entrar, deixe um título geral acima dela.
  • Coloque a apresentação antes da primeira categoria. Tudo o que vier antes dela fica de fora, então é um bom lugar para uma introdução ao livro.
  • Escreva a descrição em parágrafos comuns logo abaixo do item, sem marcadores.
  • Números com ponto ou parêntese. Números de 1 a 3 dígitos são reconhecidos. Um ano no começo de frase, como “2024 foi…”, não é tratado como número.
  • Prefira .docx. Salve o arquivo como .docx antes de importar, sobretudo se ele veio de um formato antigo.
  • Faça a prévia antes de importar. Confira a contagem de categorias e códigos e os níveis. Corrigir na prévia é mais fácil do que apagar depois.

Nomes repetidos

O programa não verifica nomes repetidos ao importar um documento nem um arquivo .qdc que tenha códigos novos. Isso tem três consequências:

  • Se o projeto já tem um código Tema e você importa outro Tema, passam a existir dois.
  • Importar o mesmo documento duas vezes cria todos os códigos em dobro, porque cada importação gera códigos novos.
  • Dois códigos com o mesmo nome em categorias diferentes são códigos separados. Isso pode ser intencional, por exemplo um código Outros em cada categoria.
O que fazer

Antes de importar, procure no painel Códigos usando o filtro da lupa. Se a importação criou duplicatas, mescle uma no outra (arraste um código sobre o outro e solte na pílula Mesclar). Se o código duplicado não tiver codificações, pode excluí-lo. Veja a página Codificação para as diferenças entre mesclar e excluir.

Diferença importante

Só a barra de codificação rápida reaproveita um código de mesmo nome no mesmo nível. Na importação, isso não acontece.
