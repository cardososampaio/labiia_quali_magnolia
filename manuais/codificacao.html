Codificação

Codificar é marcar os trechos do seu material com nomes que representam ideias, temas ou situações. Esta página mostra como criar os códigos, organizá-los, aplicá-los aos documentos e corrigi-los quando for preciso.

O que é codificar

Imagine que você leu dez entrevistas e quer reunir todas as falas em que as pessoas comentam o salário. Em vez de procurar uma a uma, você cria um código chamado Salário e o aplica a cada trecho relevante. Depois, com um clique, o programa mostra todos esses trechos, de todos os documentos, reunidos.

Pense nos códigos como papéis adesivos coloridos: você cola um deles em cada trecho que trata daquele assunto. A diferença é que os códigos ficam organizados numa lista, podem ser buscados e comparados, e o texto original nunca muda.

Os termos que aparecem nesta página
Termo O que significa
Código Um nome que representa uma ideia ou tema. Pode ter subcódigos, que são códigos dentro dele.
Trecho codificado Uma parte do material (uma frase, uma área de imagem, um intervalo de vídeo) à qual você aplicou um código. Também chamado de codificação.
Um trecho, vários códigos Um mesmo trecho pode receber mais de um código. Isso é normal e costuma ser útil.

Criar um código

  1. Abra o painel Códigos

    O painel fica ao lado da tela, com a lista de códigos do projeto.

  2. Clique no botão + do painel

    Também funciona o Novo código do menu Códigos, ou Ctrl + N.

  3. Preencha a janela Novo código

    Digite o nome do código. Escolha a cor. Se quiser, escreva uma descrição que explique o que cabe no código. Opcionalmente, defina um atalho de teclado (um número de 0 a 9).

  4. Clique em Criar

    O código aparece na lista. Sem nome, nada é salvo.

Dica

Escreva a descrição logo ao criar o código. Daqui a três meses, ela vai lembrar o critério que você usou, e isso faz diferença quando você codifica muitos documentos.

Subcódigos e hierarquia

Códigos podem ter subcódigos, e subcódigos podem ter outros subcódigos. Por exemplo, o código Trabalho pode ter os subcódigos Salário e Carga horária. Isso deixa o livro de códigos mais fácil de ler e permite buscar tudo sobre Trabalho de uma vez.

Criar um subcódigo

  1. Clique com o botão direito no código pai

    O menu de contexto se abre.

  2. Escolha Adicionar subcódigo

    Digite o nome e confirme. O subcódigo recebe a cor do pai.

Mover um código arrastando

Clique num código, mantenha o botão do mouse pressionado e arraste-o sobre outro código. O lugar onde você solta define o que acontece:

Onde soltar o código
Onde você solta O que acontece
Terço de cima da linha do outro código O código entra antes dele, no mesmo nível.
Meio da linha do outro código O código vira subcódigo dele.
Terço de baixo da linha do outro código O código entra depois dele, no mesmo nível.
Área vazia do painel O código volta para o nível principal.

Você também pode usar Mover para o nível principal no menu do botão direito. Para recolher ou expandir os subcódigos de um código, clique na setinha ao lado dele.

Cuidado

Não é possível mover um código para dentro de um dos seus próprios subcódigos. O programa não aceita essa operação.

Cores

Clique na bolinha colorida ao lado do código, ou escolha Mudar cor no menu do botão direito. Escolha uma cor da paleta ou use a opção Personalizada para outra cor.

Os subcódigos criados dentro de um código herdam a cor do pai, o que ajuda a enxergar os grupos de um relance. Na importação de um livro de códigos feito em documento, cada código-pai recebe uma cor, e os códigos dentro dele usam a mesma cor.

Atalhos com números (codificação rápida)

Um código pode ter um atalho de teclado, um número de 0 a 9. Com ele, você aplica o código a um trecho de texto em um único toque.

  1. Defina o atalho

    Ao criar ou editar o código, preencha o campo Atalho de teclado para codificação rápida.

  2. Selecione o trecho de texto

    Com o mouse, marque a parte que quer codificar.

  3. Pressione Ctrl + o número

    Por exemplo, Ctrl + 3 aplica o código que tem o atalho 3.

Cuidado

Cada número pertence a um só código. Se você der o número 3 a outro código, o atalho sai do primeiro sem nenhum aviso. Para ver quais atalhos estão em uso, confira a janela de cada código ou o livro de códigos.

Se o código não tiver atalho, o menu do botão direito avisa: Nenhum atalho definido.

Aplicar um código

Em quase todos os casos, a regra é a mesma: primeiro você seleciona o trecho, depois aplica o código. Há três caminhos principais.

Pela barra de codificação rápida

  1. Selecione o trecho

    Arraste o mouse sobre o texto, a área da imagem ou do PDF.

  2. Clique no balão Aplicar código

    O balão aparece logo depois que você solta o mouse, perto da seleção. Se ele já tiver sumido, selecione de novo.

  3. Digite parte do nome e aperte Enter

    Enter aplica o primeiro resultado da busca. As setas do teclado escolhem outro.

A barra tem outros botões, listados abaixo.

Botões da barra de codificação rápida
Botão O que faz
Codificar em… Abre a lista de todos os códigos, com os usados recentemente e a árvore completa.
Último Aplica o último código que você usou.
Novo Cria um código com o nome que você digitou e o aplica ao trecho.
Novo in vivo Cria um código cujo nome é o próprio trecho selecionado.
O que é “in vivo”?

Em análise qualitativa, código in vivo é aquele cujo nome vem das palavras exatas do participante, sem que você as reescreva. Use-o quando quiser preservar a fala original como nome do código. Quando já existir um código com o mesmo nome no mesmo nível, a barra usa esse código em vez de criar outro.

Arrastando o código para o texto

Selecione primeiro o trecho. Depois, arraste um código do painel até a seleção. Se você tiver marcado vários códigos no painel, todos são arrastados juntos. Se nada estiver selecionado, o programa avisa: Selecione um trecho primeiro e depois arraste um código para ele.

Pelo menu do botão direito

  • Com o trecho selecionado, clique com o botão direito e escolha Aplicar código. A lista mostra os códigos que têm atalho.
  • Na mesma seleção, Novo código cria um código e já o aplica ao trecho.
  • Com a seleção ativa, Adicionar como citação guarda o trecho como citação (veja a seção de memos e citações).

Em vários resultados de uma consulta

Em uma janela de resultados de consulta, clique com o botão direito e escolha Aplicar um código a todos os resultados. Você pode criar um código novo (Novo código…) ou escolher um já existente (Códigos existentes…). Isso é útil para codificar de uma vez tudo o que uma busca encontrou.

O que pode ser codificado

Como codificar cada tipo de material
Tipo de material Como codificar
Texto e nota (de caderno) Selecione palavras, frases ou parágrafos.
PDF Selecione o texto, ou desenhe uma área da página, conforme o visualizador.
Imagem Desenhe uma região da imagem e aplique o código a ela.
Áudio e vídeo Solte o código numa faixa de tempo da trilha de códigos ou selecione linhas da transcrição.
Questionário Apenas as respostas abertas das perguntas.

Regras que valem sempre

  • Se você aplicar o mesmo código ao mesmo trecho de novo, o programa não duplica a codificação.
  • Um trecho pode ter vários códigos. Cada um aparece como uma marca separada.
  • Na margem do documento, cada codificação aparece como um colchete na cor do código, com o nome dele. Memos e citações têm ícones próprios ao lado.

Ver e conferir codificações

  • Número ao lado do código: mostra quantas vezes ele foi aplicado em todos os documentos.
  • Duplo clique no código: abre, na janela de resultados de consulta, todos os trechos codificados com ele. Atenção: o duplo clique não edita o código. Para editar, use o menu do botão direito.
  • Mostrar em todos os documentos ou Mostrar no documento ativo (botão direito no código): cria uma consulta com esse código, para você ver o resultado com mais opções.

Remover uma codificação

Para tirar um código de um trecho, clique com o botão direito sobre a marca dele no texto e escolha Remover código. Se o trecho tiver mais de um código, o programa lista todos para você escolher. Quando sai o último código do trecho, o próprio trecho codificado desaparece.

Remover não é excluir

Tirar um código de um trecho não apaga o código do projeto. Ele continua no painel e pode ser aplicado de novo.

Atalhos úteis

Teclas que ajudam na codificação
Teclas O que faz
Ctrl + N Cria um novo código.
Ctrl + 0 a 9 Aplica ao trecho selecionado o código que tem esse atalho.
Ctrl + Z Desfaz a última mudança.
Ctrl + Shift + Z Refaz a mudança desfeita.
Enter Confirma o nome ao renomear; na barra de codificação rápida, aplica o primeiro resultado.

Renomear, editar, mesclar e excluir

Há quatro maneiras de mudar um código depois de criado. Elas não são equivalentes, então vale conhecer cada uma.

Ações sobre um código existente
Ação Como fazer Quando usar
Renomear Botão direito > Renomear. O nome vira campo de texto na própria linha. Quando você só quer trocar o nome.
Editar código Botão direito > Editar código. Abre uma caixa com nome, cor, descrição e atalho. Quando quer mudar mais de um campo de uma vez.
Mesclar Arraste um código sobre outro e solte na pílula Mesclar. Quando dois códigos são, na verdade, o mesmo.
Excluir Botão direito > Excluir. Quando o código não deve existir no projeto.

Mesclar dois códigos

Mesclar faz todas as codificações de um código passarem para outro. Use quando, por exemplo, você tiver criado Salário e Salario mensal para a mesma ideia.

  1. Arraste o código que vai desaparecer

    Arraste-o sobre o código que vai ficar.

  2. Solte na pílula Mesclar

    Ela aparece à direita da linha de destino.

  3. Confirme

    A caixa pergunta “Mesclar X em Y?” e informa quantos trechos serão recodificados. Clique em Mesclar para concluir.

Antes de mesclar
  • Os subcódigos do código que sai também saem do painel. Antes de mesclar, mova os subcódigos que quer manter para outro lugar.
  • O programa não verifica se o trecho já tinha o código de destino. Por isso, um trecho que tinha os dois códigos pode ficar com o de destino duas vezes. Confira depois com a busca.
  • A caixa diz que a mesclagem não pode ser desfeita, mas o Ctrl + Z também a desfaz. Salve o projeto antes, para ter um ponto de volta seguro.

Excluir um código

Botão direito no código > Excluir. Ele sai do painel, junto com todos os seus subcódigos.

Atenção

Excluir não pede confirmação. As codificações desse código continuam nos documentos, mas aparecem como Desconhecido, porque o código já não existe. Se você excluiu sem querer, use logo o Ctrl + Z. Para tirar a codificação de um trecho específico, use Remover código. Para trocar um código por outro, prefira Mesclar.

Filtrar a lista

Clique na lupa no cabeçalho do painel Códigos e digite parte do nome. A lista mostra só os códigos que correspondem, com os códigos pais aparecendo esmaecidos para você ver a hierarquia. Pressione Esc para fechar a busca.

Atributos e Características

Códigos marcam trechos. Atributos e características descrevem documentos inteiros: quem é a pessoa entrevistada, em que cidade ela mora, em que data foi feita a entrevista, em que grupo ela estava. Essas informações servem para filtrar e comparar os documentos depois.

  • Característica: uma marca que você aplica a um documento. Exemplos: Entrevista, Grupo A.
  • Atributo: um grupo de características que tem um tipo. Exemplo: Escolaridade.
  • Características sem atributo: ficam no grupo Sem atributo, sem tipo definido.

Os quatro tipos de atributo

Tipos de atributo
Tipo O que guarda Exemplo
Texto Qualquer texto que você digitar. Cidade: Belo Horizonte
Data Uma data nos formatos dd/mm/aaaa, mm/aaaa ou aaaa. Data da entrevista: 03/2024
Numérica Somente números. Idade: 34
Lista Uma lista fixa de opções que você define. Escolaridade: Fundamental, Médio, Superior

Criar um atributo

  1. Abra o gerenciador

    No grupo Codificação da barra, clique em Características. Também funciona pelo menu Documentos > Gerenciar características dos documentos.

  2. Clique em Adicionar atributo

    Digite o nome, por exemplo Escolaridade, e escolha o tipo.

  3. Defina os valores

    Para o tipo Lista, digite as opções separadas por vírgula, por exemplo Fundamental, Médio, Superior. Depois, se precisar mudar, use Editar opções da lista (uma opção por linha). Para os outros tipos, digite cada valor no campo Adicionar valor dentro do atributo e pressione Enter.

  4. Clique em Adicionar

    O atributo aparece na lista. Clicar no nome dele, depois, permite renomear.

Aplicar a documentos

  1. Escolha o documento

    Clique com o botão direito no documento e escolha Editar características…, ou arraste a característica até o documento na lista de documentos. Você também pode arrastá-la até uma pasta, e todos os documentos da pasta a recebem.

  2. Marque as caixas

    Ligue ou desligue cada característica. Com vários documentos selecionados, a mudança vale para todos.

A característica fica ligada ao documento. Para removê-la só daquele documento, desmarque a caixa dela. Atributos e características também podem ser aplicados a respondentes e perguntas de questionários.

Exemplo prático: Escolaridade

Crie o atributo Escolaridade com o tipo Lista e as opções Fundamental, Médio, Superior. Na entrevista da participante 07, marque a característica Superior. Depois, use Selecionar documentos com esta característica sobre Superior: o programa seleciona todas as entrevistas de pessoas com ensino superior, pronto para você consultar só esse grupo.

Cuidados ao excluir
  • Excluir um atributo apaga também as características dele e as ligações com os documentos. Não há confirmação.
  • Excluir uma característica remove só a ligação com os documentos. Os documentos continuam no projeto.
  • Excluir uma pasta que tem notas pede confirmação e avisa que os códigos, citações e memos dessas notas também serão excluídos.

Memos

Um memo é uma anotação sua: uma interpretação, uma dúvida, uma ideia para a análise. Ele fica guardado no projeto, junto aos dados, e não aparece no texto do documento. Escreva memos com frequência; eles são a parte do trabalho que mostra como você chegou às conclusões.

Tipos de memo
Tipo Como criar Fica ligado a
Memo do projeto Painel Memos > + > Memo do projeto. Nada específico; é uma anotação geral.
Memo de documento Painel Memos > + > Memo de documento (com um documento aberto). O documento aberto.
Memo de seleção Selecione um trecho, clique com o botão direito e escolha Adicionar memo à seleção. O trecho selecionado.
  • Editar: dê duplo clique no memo, ou escolha Editar memo. Ele abre numa janela própria, com título, texto formatado e o botão Salvar e fechar.
  • Excluir: o programa pede confirmação.
  • Soltar o vínculo: se você arrastar um memo de documento ou de seleção para Memos do projeto, ele deixa de estar ligado ao documento. O programa pede confirmação.
Atenção

Ctrl + Z não desfaz memos. Excluir um memo é definitivo.

Citações

Uma citação é um trecho que você quer destacar, por exemplo uma fala forte ou exemplar. Selecione o trecho, clique com o botão direito e escolha Adicionar como citação. Ela aparece na margem com um ícone próprio. Citações não são códigos: para classificar o trecho por tema, aplique também um código.

Diário de bordo

O diário de bordo é um caderno para registrar o processo da pesquisa: decisões, mudanças de critério, dúvidas, reuniões com orientador. Ele não fica ligado a documentos nem a códigos, e serve para você contar, depois, como a análise foi feita.

  1. Abra o diário

    Use o botão Diário de bordo no grupo Codificação, ou o menu Códigos.

  2. Clique em + Entrada

    Digite o título e escreva o conteúdo. A entrada mais recente aparece primeiro na lista.

  3. Edite quando quiser

    Um clique mostra a entrada. Duplo clique a edita. No botão direito, você também encontra Editar entrada e Excluir entrada.

  4. Exporte, se precisar

    O botão Exportar PDF gera o diário inteiro em PDF.

Atenção

O diário não entra no Ctrl + Z. Excluir uma entrada pede confirmação, e ela não pode ser recuperada depois disso.

Desfazer e refazer

Ctrl + Z desfaz a última mudança, e Ctrl + Shift + Z refaz. Os mesmos comandos estão nos botões Desfazer e Refazer da barra de título.

  • O programa guarda até 50 passos. Mudanças seguidas, feitas em menos de meio segundo, contam como um passo só.
  • Desfaz: documentos e seus trechos, codificações, códigos (criar, renomear, mover, mesclar e excluir), atributos e características, consultas e citações.
  • Não desfaz: memos e o diário de bordo.
  • Dentro de um campo de texto, como o nome de um código ou a descrição, o Ctrl + Z age sobre o próprio campo, da forma usual.
Cuidado

Se você fez uma mudança importante e depois outras, desfazer volta uma de cada vez. Não conte com o Ctrl + Z para recuperar algo que você escreveu em memos ou no diário.

Quando o projeto está com outra pessoa

Em um projeto compartilhado, o programa reserva o projeto automaticamente para quem faz a primeira alteração. Para isso, é preciso ter seu nome configurado em Preferências > Seu nome. Se você ainda não configurou, o programa pergunta na primeira vez.

Se outra pessoa estiver com o projeto, aparece o botão vermelho Bloqueado na barra de título. Ao tentar criar, excluir, renomear, mesclar, mover códigos ou aplicá-los ao texto, o programa mostra um aviso com três opções:

  • Assumir o controle mesmo assim: use só se a outra pessoa já parou de trabalhar nele.
  • Criar uma cópia: cria um arquivo ao lado do original, para você trabalhar sem perder nada. Depois, use a ferramenta de mesclagem de projetos para juntar as duas versões.
  • Cancelar: o projeto fica só para leitura.
Boas práticas
  • Comece com poucos códigos amplos e vá dividindo-os em subcódigos conforme o material exige.
  • Escreva a descrição de cada código, com o critério de entrada.
  • Salve o projeto antes de mesclar ou excluir códigos.
  • Use memos para registrar a interpretação, e não só a classificação.

Para importar um livro de códigos pronto, de um arquivo .qdc ou de um documento de texto, veja a página Livro de códigos.
