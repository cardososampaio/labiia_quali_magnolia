Documentos e fontes

Fonte é qualquer material que você traz para a pesquisa: um texto de entrevista, um PDF, uma foto, um áudio, um vídeo ou uma planilha de questionário. Esta página explica quais arquivos entram, como importá-los, como organizá-los no painel Documentos e como ler cada tipo.

O que é uma fonte

Quando você importa um arquivo, o labiia_quali guarda uma cópia dele dentro do projeto. Por isso, depois de importado, o documento faz parte do seu projeto (arquivo .qdpx) e não depende mais da pasta de origem. Você pode mexer ou apagar o arquivo original sem perder a fonte.

Cada fonte aparece no painel Documentos, na lateral da tela. É ali que você organiza, abre e lê o material. A codificação, isto é, marcar trechos com códigos, é tratada em Codificação.

Tipos de arquivo aceitos

O programa aceita os tipos abaixo. Quando um tipo é convertido na importação, a tabela diz o que você vê depois.

Tipos de fonte aceitos e o que acontece com cada um
Tipo Extensões O que você vê no programa
Texto simples .txt O texto aparece para leitura e seleção de trechos.
Markdown .md, .markdown Texto com a formatação mostrada, para leitura e seleção.
PDF .pdf Páginas com rolagem, zoom e dois modos de seleção.
Word .docx Convertido para PDF na importação e lido como PDF.
RTF .rtf Convertido para PDF na importação e lido como PDF.
OpenDocument (LibreOffice, BrOffice) .odt Convertido para PDF na importação e lido como PDF.
Questionário .csv, .xlsx Vira um questionário, com respondentes e perguntas. Em .xlsx, só a primeira planilha é lida.
Imagem .jpg, .jpeg, .png, .gif, .webp A imagem aparece com zoom e seleção de região.
Imagem convertida .tif, .tiff, .heic, .heif Convertida para PNG na importação. Você passa a ver a versão PNG.
Áudio .wav, .mp3, .ogg, .flac, .m4a, .aac Player com controles e área de transcrição.
Vídeo .mp4, .mov, .avi Player com o vídeo acima da área de transcrição.
Word antigo (.doc) não entra

Arquivos .doc do Word antigo não entram. O programa avisa que não conseguiu abrir o arquivo e pede para salvá-lo como .docx. Abra o arquivo no Word ou no LibreOffice, use Salvar como e escolha o formato .docx. Depois importe a versão nova.

Pastas e arquivos sem extensão

Você não pode importar uma pasta inteira. Abra a pasta e arraste os arquivos de dentro dela. Arquivos sem extensão também são recusados. Se o tipo não for aceito, o programa avisa com a frase O labiia_quali não importa arquivos .ext, trocando ext pela extensão do arquivo.

Importar fontes

Você pode importar quantos arquivos quiser de uma vez. Há três caminhos, todos com o mesmo resultado:

  • Botão + no cabeçalho do painel Documentos (a dica do botão mostra Importar fontes).
  • Aba Início e botão Importar.
  • Menu Iniciar e opção Importar fontes…. Também existe Arquivo > Importar documento….
  1. Abra um projeto

    A importação só funciona com um projeto aberto. Se a tela estiver vazia, comece por Projetos.

  2. Escolha a forma de importar

    Clique em + no painel Documentos ou use um dos caminhos da lista acima.

  3. Selecione os arquivos

    Na janela Importar documento, use Ctrl + clique para escolher arquivos separados, ou Shift + clique para escolher um intervalo. Depois clique em Abrir.

  4. Confira a lista

    Os arquivos aparecem no painel Documentos, cada um com a cor do seu tipo. Se algum arquivo não entrar, aparece a mensagem Não foi possível importar N arquivo(s), com o nome de cada um e o motivo.

Arrastar arquivos do Explorador

Você também pode arrastar arquivos da pasta do Windows (Explorador de Arquivos) direto para o painel Documentos:

  • Se soltar sobre uma pasta da lista, os arquivos entram nela.
  • Se soltar sobre a área vazia do painel, os arquivos entram na raiz (o nível mais alto da lista).

Organizar no painel Documentos

O painel é uma lista com pastas e documentos. Você pode criar a organização que quiser, por exemplo uma pasta para cada grupo de entrevistas.

Pastas e cadernos

  • Criar nova pasta (ícone de pasta com +) cria uma pasta. Use o menu da pasta para criar uma subpasta.
  • Criar caderno (ícone de caderno com lápis) cria um caderno. O caderno guarda apenas notas escritas no programa. Veja Notas e memos.
  • Clique numa pasta para abrir ou fechar. A seta à esquerda mostra se ela está aberta.

Buscar

Clique na lupa Filtrar documentos para abrir o campo de busca. A busca procura pelo nome de documentos e pastas, sem diferenciar maiúsculas de minúsculas. Pastas que contêm um resultado continuam visíveis, com aparência mais clara. A busca não procura dentro do texto nem nas características. Para fechar a busca, pressione Esc ou clique no X.

Renomear, mover e reordenar

  1. Renomear

    Clique com o botão direito no item e escolha Renomear. O nome vira um campo na própria linha. Pressione Enter para salvar ou Esc para cancelar. Um nome vazio não é salvo.

  2. Mover para uma pasta

    Arraste o documento sobre a pasta de destino. Também é possível clicar com o botão direito e escolher Mover para pasta. Para levar algo de volta à raiz, use Mover para a raiz.

  3. Mover várias fontes de uma vez

    Selecione várias com Ctrl + clique (escolhe ou desfaz uma) ou Shift + clique (escolhe um intervalo). Depois arraste o grupo para a pasta.

  4. Reordenar

    Arraste o documento para cima ou para baixo, numa linha que aparece entre os itens. Pastas também podem ser arrastadas para dentro de outra pasta.

Remover fontes e pastas

Clique com o botão direito em um ou mais documentos e escolha Remover documento (ou Remover N documentos). Para apagar uma pasta, escolha Excluir pasta.

Remover documento não pede confirmação

Ao escolher Remover documento, o documento sai do projeto na hora, sem janela de confirmação. Os memos e as citações ligados a ele também são apagados. Não há desfazer nesta ação. Antes de remover, confira a seleção. Se estiver em dúvida, copie o arquivo original para outro lugar antes.

Excluir pasta não apaga os documentos

Quando você exclui uma pasta, os documentos que estavam dentro dela voltam para a raiz. Só a pasta some. Pastas com notas (cadernos) pedem confirmação antes de apagar as notas.

Ler cada tipo

Para abrir um documento, dê duplo clique nele. Ele abre numa aba na área principal. Você também pode clicar com o botão direito e escolher Exibir. Abas podem ser fechadas com o X.

Texto, Markdown, Word, RTF e OpenDocument

O texto aparece para leitura. Para marcar um trecho, selecione-o com o mouse. Aparece o balão Aplicar código, e você também pode clicar com o botão direito na seleção para adicionar um memo ou uma citação.

O texto importado não se edita

O texto de uma fonte importada é só para leitura. Se precisar corrigir o arquivo, faça a correção no arquivo original, remova a fonte e importe a versão corrigida. As notas, que você escreve no programa, podem ser editadas normalmente.

PDF

O PDF mostra as páginas, com rolagem. Na barra no topo, há dois modos de seleção:

  • Seleção de texto (padrão): você seleciona palavras e frases com o mouse, como num texto comum.
  • Seleção de área: você desenha um retângulo sobre a página. Use quando o trecho é uma tabela, uma figura ou uma área do desenho da página.

Para ampliar ou reduzir, use os botões Aumentar zoom, Diminuir zoom, Voltar para 100% e Ajustar à tela. Enquanto o arquivo carrega, aparece a mensagem Carregando PDF.... Se o arquivo original tiver sumido do projeto, aparece Arquivo PDF indisponível.

Imagens

A imagem abre com o mesmo zoom do PDF. Para marcar uma parte, clique e arraste o mouse para desenhar um retângulo sobre ela. Esse retângulo é a região selecionada, e pode receber códigos e memos. Se o arquivo tiver sumido, aparece Arquivo de imagem indisponível.

Áudio e vídeo

O áudio mostra uma forma de onda e um player com estes controles:

  • Reproduzir e Pausar.
  • Voltar e Avançar. Segure o botão para repetir o movimento.
  • Controle de volume e botão de mudo.

O vídeo tem os mesmos controles, com a imagem acima da área de texto da transcrição. Se um vídeo .mov ou .avi não tocar, converta-o para .mp4 e importe de novo.

Transcrever áudio e vídeo

A transcrição é manual

O labiia_quali não transcreve a fala sozinho. Ele não reconhece as palavras do áudio. Quem escreve o texto é você (ou alguém da equipe). O programa ajuda a escrever: ele grava o instante do áudio em que cada linha começa.

Para que serve: transcrever é passar a fala para texto escrito, para poder ler, codificar e buscar. Um texto transcrito também pode ser importado, se você já tiver a transcrição em outro programa.

Escrever a transcrição

  1. Abra o áudio ou o vídeo

    Dê duplo clique no documento no painel Documentos.

  2. Mude para o modo de transcrição

    Clique na aba Modo de transcrição (ou em Mudar para o modo de transcrição). A área de texto aparece.

  3. Digite a fala

    Clique na área de texto e escreva. A cada Enter, a nova linha recebe automaticamente o instante em que o áudio está tocando. Por isso, toque o áudio, pause quando precisar e continue escrevendo.

  4. Volte e ouça de novo

    Use Voltar, Avançar e Reproduzir para ouvir de novo um trecho difícil.

  5. Passe para a codificação

    Quando terminar, clique na aba Modo de codificação. Ali aparece uma trilha de tempo acima do texto. Clicar numa linha leva o player até aquele instante.

No modo de transcrição, a codificação fica bloqueada

Enquanto você está transcrevendo, a mensagem Digite para transcrever. A codificação fica bloqueada. aparece. Para codificar, mude para o Modo de codificação.

Importar uma transcrição pronta

Se você já tem a transcrição em arquivo, pode importá-la no modo de transcrição, pelo botão de importar (ou em Arquivo > Importar transcrição). Formatos aceitos:

Formatos de transcrição que podem ser importados
Formato O que entra
.txt O texto, sem tempos.
.md O texto em Markdown, sem tempos.
.srt e .vtt Legendas: o texto limpo, com o tempo de cada linha.
.html Transcrição exportada pelo noScribe: texto com o tempo de cada linha. As informações do cabeçalho viram um memo do documento, com o título Notas da transcrição importada.

Ao importar, o programa pode perguntar se você quer codificar automaticamente as falas de cada pessoa. Aceite só se a transcrição indicar quem está falando com clareza.

Exportar a transcrição

Para levar o texto para outro programa, use Exportar transcrição e escolha Exportar como TXT, Exportar como Markdown ou Exportar como PDF.

Questionários (CSV e XLSX)

Um questionário é uma planilha em que cada pessoa que respondeu ocupa uma linha. Ao importar, o programa separa as pessoas e as perguntas, para você analisar cada resposta.

Importar

  1. Escolha o arquivo

    Use o mesmo botão + ou arraste o arquivo .csv ou .xlsx para o painel.

  2. Confira o formato

    A janela Importar questionário reconhece sozinha três formatos: SurveyMonkey, Microsoft Forms e Genérico (uma linha de cabeçalho). Se a detecção não tiver certeza, a janela pede que você confirme. Você também pode trocar o formato ali.

  3. Ajuste os tipos de pergunta

    Cada coluna de resposta vira uma pergunta com um tipo. Clique no tipo para trocá-lo antes de importar.

  4. Importe

    Se você escolheu vários arquivos, cada questionário abre numa janela, um depois do outro.

Como as colunas viram dados

  • Cada linha da planilha é um respondente. Se houver colunas de nome, o programa usa o primeiro e o último nome. Se não houver, cria o nome Respondente N.
  • Colunas de identificação (como ID, data de início, e-mail e nome) identificam quem respondeu. Elas não viram perguntas.
  • Cada coluna de resposta vira uma pergunta.

Tipos de pergunta

Tipos de pergunta e como são reconhecidos
Tipo O que é Pode receber códigos?
Aberta Texto livre. Respostas longas ou com muitos valores diferentes caem aqui. Sim
Escolha única Uma opção entre várias. Respostas curtas e repetidas caem aqui. Não
Múltipla escolha Várias colunas que formam uma só pergunta, em que a pessoa marca mais de uma opção. Não
Numérica Números, como idade ou renda. Não
Só respostas abertas recebem códigos

A codificação é feita nas respostas abertas. Respostas de escolha, respostas numéricas e os dados de identificação não recebem códigos. Para ver o resultado das escolhas, use o Resumo do questionário, que é explicado abaixo.

Navegar pelo questionário

  • Na árvore, o questionário tem ícone violeta e dois grupos: Respondentes (N) e Perguntas (M).
  • Clique no questionário para abrir o Resumo do questionário. Ele mostra a distribuição das respostas e, para perguntas numéricas, valores como a mediana. O botão Exportar PDF gera um arquivo do resumo.
  • Clique em um respondente para ver as respostas dele. Clique em Mostrar respostas → para abrir a lista completa.
  • Clique em uma pergunta para ver a distribuição das respostas dela.
  • Para escolher vários respondentes ou perguntas, use Ctrl + clique. Assim você aplica uma característica a todos de uma vez.

Atributos e características

Atributos e características são formas de classificar as fontes e as pessoas do questionário. Eles não mudam o texto. Servem para você separar e comparar grupos depois.

  • Atributo é o tipo de informação que você quer registrar, a pergunta de classificação. Exemplos: Gênero, País, Cidade.
  • Característica é o valor que você aplica. Exemplos: Feminino, Masculino, Brasil.

Exemplo

Você tem 20 entrevistas e quer separar as mulheres dos homens nas análises:

  1. Crie o atributo Gênero

    Escolha o tipo Lista, que mostra opções fixas. Em Editar opções da lista, digite as opções separadas por vírgula, por exemplo Feminino, Masculino.

  2. Crie as características dentro do atributo

    As características Feminino e Masculino ficam dentro do atributo Gênero. Assim você tem a característica Gênero: Feminino.

  3. Aplique a característica à entrevista

    Clique com o botão direito na entrevista e escolha Editar características…. Ou arraste a característica Feminino sobre a entrevista. Você pode fazer o mesmo com um respondente de questionário.

Para criar e organizar atributos e características, use Documentos > Gerenciar características dos documentos. Ali, o botão Adicionar atributo cria um atributo novo.

Tipos de atributo

Tipos de atributo
Tipo Uso
TextoQualquer texto curto, como o nome de uma cidade.
DataDatas, usadas para linhas do tempo na análise. Formatos aceitos: dd/mm/aaaa, mm/aaaa e aaaa.
NuméricaNúmeros, como idade.
ListaOpções fixas, como Feminino e Masculino.
Característica sem atributo

Você pode criar uma característica sem colocá-la em nenhum atributo, como Entrevistado. Ela aparece como Sem atributo.

Para saber como usar características ao codificar trechos, veja Codificação.

Notas e memos

Além das fontes importadas, o painel aceita dois tipos de texto escrito por você:

  • Notas são textos que você escreve no programa. Ficam em um caderno. Clique no + do caderno (ou clique com o botão direito e escolha Nova nota) para criar uma. A nota tem título e pode ser editada. Ao renomear, o prefixo com data e hora continua no nome.
  • Memos são anotações que você liga a uma fonte ou a um trecho. Para o documento inteiro, use o botão Adicionar memo no cabeçalho do documento. Para um trecho, selecione o texto, clique com o botão direito e escolha Adicionar memo à seleção. Os memos aparecem no painel Memos.
Documentos não ficam dentro de cadernos

O caderno aceita apenas notas. Para organizar fontes importadas, use pastas.

Se o antivírus bloquear os arquivos

Antivírus (Avast e outros) pode bloquear a importação

Alguns antivírus protegem arquivos de pastas como a Área de Trabalho e Documentos. Quando isso acontece, o Windows não deixa o labiia_quali ler os arquivos, e aparece esta mensagem:

O Windows não deixou o labiia_quali abrir estes arquivos. Em geral é o antivírus protegendo documentos de pastas como a Área de Trabalho ou Documentos (no Avast: Proteção → Escudo de dados confidenciais ou Escudo contra ransomware). Permita o labiia_quali no antivírus, ou copie os arquivos para outra pasta, e importe de novo.

Você tem duas saídas:

  1. Liberar o programa no antivírus. No Avast, abra Proteção e procure o escudo citado na mensagem (os nomes das opções podem mudar conforme a versão). Permita o labiia_quali nesse escudo. Depois, importe os arquivos de novo.
  2. Copiar os arquivos para outra pasta. Copie os arquivos para uma pasta fora da Área de Trabalho e de Documentos, por exemplo uma pasta de projeto como C:\Pesquisa. Importe a partir dessa pasta.
