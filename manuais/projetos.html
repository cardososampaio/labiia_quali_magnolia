Projetos

Um projeto é o arquivo onde o labiia_quali guarda tudo o que você faz numa pesquisa: documentos, códigos, codificações, memos, consultas e análises salvas. Esta página mostra como criar, abrir, gravar e fechar esse arquivo, como trocar projetos com outros programas e como trabalhar em equipe.

O arquivo do projeto

Cada projeto é um único arquivo com a extensão .qdpx. Dentro dele ficam os documentos importados (textos, PDFs, áudios, vídeos e imagens), a lista de códigos, as codificações, os memos, as citações, as consultas e as análises salvas.

O formato .qdpx segue o padrão REFI-QDA, de troca de projetos de análise qualitativa, aceito por programas como NVivo, ATLAS.ti e MAXQDA. Veja a seção Trocar projetos com outros programas.

Dica

O arquivo é o projeto: se ele se perder, o trabalho se perde junto. Guarde cópias de segurança em outro lugar, como outro disco ou uma pasta sincronizada na nuvem.

Um livro de códigos também pode ser importado de um arquivo .qdc, o padrão REFI-QDA para livros de códigos. Isso ajuda a reaproveitar os mesmos códigos em outro projeto. Veja Livro de códigos.

Criar um projeto

Um projeto novo começa vazio. Você escolhe onde ele será gravado e como se chama o arquivo.

  1. Clique em Novo

    Está na aba Início, no grupo Fontes. Também funciona pelo menu Iniciar, com Novo projeto, ou pelo botão Novo da tela de boas-vindas.

  2. Escolha o lugar e o nome do arquivo

    Na janela Criar novo projeto, escolha a pasta e digite o nome. O programa sugere um nome para você trocar.

  3. Confirme

    O arquivo .qdpx vazio é criado no disco na hora. O nome do projeto aparece na barra de título, com o estado Salvo.

Cuidado

Se você tinha outro projeto aberto com alterações, o programa salva esse projeto antes de trocar pelo novo.

Abrir um projeto

Há quatro jeitos de abrir um projeto existente:

  • pressione Ctrl + O;
  • clique em Abrir na aba Início, no grupo Fontes;
  • no menu Iniciar, escolha Abrir projeto…;
  • na tela de boas-vindas, clique em um dos projetos recentes ou em Abrir….

Os projetos recentes

O programa lembra dos últimos projetos que você abriu, com o nome e o caminho do arquivo. Há três lugares para vê-los:

Onde aparecem os projetos recentes
Onde Quantos aparecem
Tela de boas-vindas Todos os guardados (até 10). Há o botão Limpar, que esvazia a lista.
Seta ▾ do botão Abrir Até 10, com a opção Procurar outro projeto… no fim.
Menu Iniciar Até 8.

Um arquivo que foi apagado ou movido sai da lista sozinho. Se você mudou um projeto de pasta, abra-o de novo pelo Procurar outro projeto… para ele voltar a aparecer nos recentes.

Ao abrir, o programa verifica se outra pessoa está com o projeto bloqueado. Se estiver, leia a seção Trabalho em equipe.

Salvar

O labiia_quali salva o seu trabalho de três formas: manual, automática e como cópia.

Salvar manualmente

Pressione Ctrl + S ou clique no botão Salvar (ícone de disquete) na barra de título. O projeto é gravado no mesmo arquivo.

Se o projeto ainda não tem arquivo, o programa abre a janela Salvar projeto QDPX, para você escolher onde gravar.

Salvar automaticamente

Depois de uma alteração, o programa grava sozinho cerca de 2 segundos depois. Na barra de título, o estado muda de Editado para Salvo.

Cuidado

O salvamento automático não funciona em dois casos: quando o projeto ainda não tem arquivo (use Ctrl + S para escolher o lugar) e quando outra pessoa está com o projeto bloqueado.

Salvar como…

Use Ctrl + Shift + S ou o item Salvar como… do menu Iniciar para gravar uma cópia com outro nome. A partir daí, você trabalha na cópia, e o arquivo original fica como estava.

Dica

Antes de uma mudança grande, como uma nova rodada de codificação ou uma mesclagem, use Salvar como… e dê um nome com a data. Assim você tem um ponto para voltar.

Proteções do programa

  • Projeto que foi assumido por outra pessoa: se alguém pegou o projeto depois que você o abriu, o programa recusa a gravação e mostra o aviso de bloqueio. Assim o trabalho dela não é sobrescrito sem você ver.
  • Projeto vazio: o programa não grava um projeto vazio por cima de um arquivo que já tinha dados.

Fechar o programa

Ao fechar a janela (com o X, com Alt + F4, ou pelo botão Sair da tela inicial), o programa pergunta:

Fechar o labiia_quali?
O projeto é salvo automaticamente antes de fechar.

  • Sim: grava o que estiver pendente e fecha.
  • Cancelar: volta para o programa. Este é o botão padrão, para evitar fechamento por engano.

O programa não pergunta quando o Windows está desligando ou reiniciando, nem quando está fechando para instalar uma nova versão.

Trocar projetos com outros programas

Como o formato .qdpx segue o padrão REFI-QDA, a troca de projetos é possível com programas de análise qualitativa que aceitam esse padrão, como o NVivo, o ATLAS.ti e o MAXQDA. O resultado depende de cada programa, por isso confira a troca.

Também dá para ir na direção contrária. O labiia_quali grava o projeto no mesmo padrão: use Salvar como… para gravar uma cópia .qdpx e abra essa cópia no outro programa.

Trazer um projeto de outro programa

  1. Exporte o projeto no outro programa

    Use a opção de exportação em formato REFI-QDA (.qdpx) do programa de origem. Consulte o manual dele para ver como fazer.

  2. Abra o arquivo .qdpx aqui

    Use Ctrl + O ou o botão Abrir.

  3. Confira o projeto

    Veja se documentos, códigos e codificações chegaram como você esperava, antes de continuar o trabalho.

Atenção

O arquivo nativo do NVivo (.nvp) não abre direto no labiia_quali. Exporte o projeto do NVivo no formato REFI-QDA (.qdpx) e abra esse arquivo.

Cuidado

Não existe garantia de que todos os detalhes de um programa passem para outro. Por isso, confira o resultado da troca. Guarde o projeto original, sem alterações, como cópia de segurança.

Trabalho em equipe

Quando mais de uma pessoa trabalha no mesmo projeto, cada uma tem uma cópia do arquivo. O labiia_quali controla quem está com o projeto. Não há um botão de "retirar" ou "devolver": o controle é automático.

Como funciona

  • Seu nome: o programa pede o seu nome na primeira abertura. Ele aparece para os colegas e fica gravado no projeto quando você é a última pessoa a editá-lo. Você pode mudá-lo em Preferências, na categoria Geral.
  • Reserva automática: quando você começa a alterar um projeto salvo, o programa o marca como seu. É o que se chama de check-out: a pessoa "pega" o projeto para editar.
  • Projeto em uso: se outra pessoa está com o projeto, aparece o botão vermelho Bloqueado na barra de título.

O que aparece quando o projeto está bloqueado

Clique em Bloqueado para ver quem está com o projeto e desde quando. A janela é Este projeto está em uso, com estas opções:

Opções quando o projeto está em uso por outra pessoa
Botão O que acontece
Cancelar Você fica só em modo de leitura. Pode ver o projeto, mas não altera nada.
Criar uma cópia Você trabalha numa cópia separada. Depois, pode trazer as alterações para o projeto principal com a mesclagem.
Assumir o controle mesmo assim Você passa a ser o responsável pelo projeto. Use só quando a outra pessoa já parou de trabalhar: se ela ainda estiver editando, as alterações de vocês podem se sobrepor.
Atenção

Se as duas pessoas salvarem ao mesmo tempo, uma pode sobrescrever o trabalho da outra. Combine com a equipe antes de usar essa opção.

Com o projeto bloqueado, as ações que alteram o projeto (importar, criar código, criar pasta, aplicar código) ficam indisponíveis. Ao tentar uma delas, o programa explica o motivo.

Mesclar projetos

Mesclar é trazer para o seu projeto as diferenças de outra cópia do mesmo projeto. Use quando um colega trabalhou numa cópia enquanto você trabalhava na sua. O programa compara as duas e mostra cada diferença para você escolher o que entra.

A entrada para a mesclagem é somente Mesclar projetos…, no menu Iniciar.

  1. Abra o menu Iniciar e escolha Mesclar projetos…

    Clique no botão Iniciar, no canto da barra de título, ou pressione Alt + Home.

  2. Escolha o outro arquivo

    Selecione o arquivo .qdpx da outra cópia, o que tem o trabalho do colega.

  3. Espere a comparação

    Aparece a aba Mesclar projeto, com o título Comparando com o nome do arquivo. Enquanto compara, o programa mostra Comparando projetos…. Se a outra cópia tiver uma última edição registrada, aparece o nome de quem editou por último.

  4. Leia as seções da lista lateral

    As diferenças estão separadas por assunto: Documentos, Texto dos documentos, Codificações, Códigos, Características, Atributos, Memos, Citações, Diário de bordo, Consultas salvas, Pastas e Análises salvas. Clique em cada uma para ver as diferenças.

  5. Escolha o que entra

    Dentro de cada seção, as diferenças aparecem em grupos: Só no meu (ou Suas alterações não salvas, quando o projeto estava bloqueado), Só em seguido do nome da outra pessoa (por exemplo, Só em Ana), e Diferente. Uma mudança de nome aparece como Renomeado. Marque a caixa de cada diferença que você quer aceitar. Use Selecionar tudo ou Desmarcar tudo para agilizar.

  6. Aplique

    Clique em Continuar (ou em Aplicar N alteração(ões) aprovada(s)). Para sair sem mudar nada, clique em Cancelar.

  7. Salve

    Aparece Mesclagem aplicada, com o número de alterações feitas. As mudanças estão no projeto, mas ainda não no arquivo. Clique em Salvar para gravar.

Dica

Se você assumiu um projeto que estava bloqueado, a mesclagem abre sozinha, para você conciliar as alterações.

Cuidado

Antes de mesclar, use Salvar como… para guardar uma cópia do seu projeto. Se a mesclagem não ficar como você quer, a cópia permite voltar atrás.
